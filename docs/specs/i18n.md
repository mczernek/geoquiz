# Languages

The app speaks **English** and **Polish** (decision 014).

## Choosing

- First launch: the device's language if it's Polish, otherwise English.
- Account → Language: English / Polski. The choice is remembered on the device (not synced to other devices).
- The web page's `lang` follows the app's language.

## What is translated

- All UI text: `src/i18n/en.ts` defines the shape; `src/i18n/pl.ts` must fill every key (TypeScript enforces it).
  Strings that include numbers or names are functions, so each language controls its own word order.
- Country names and capitals: `name` / `capitals` (English) and `namePl` / `capitalsPl` (Polish) in
  `src/data/countries.json`, built by `pnpm data` (Polish country names from world-countries with fixes in
  `scripts/build-data.mjs`, Polish capitals from `scripts/data/capitals-pl.json`).
- Continent and topic names. Lists (Progress) sort by the localized name.

## Answers

Typed answers are accepted in either language, whatever the UI language ("Germany", "Niemcy" and "Deutschland" are
all right; so are "Warsaw" and "Warszawa"), with the usual forgiveness for accents and typos
(`docs/specs/learning.md`).

## Polish grammar

Names only exist in the nominative, so prompts put them after a colon or at the start of the sentence:
"Wskaż flagę: Niemcy", "Niemcy – stolica to…", "Berlin to stolica…", "Znajdź na globie: Niemcy". Counts use
the "Label: n" form ("Opanowane: 5 z 46") so no plural forms are needed.
